# Abel Engineering Portal

This folder is the complete upload content for the **portal repository only**.

It intentionally contains **no copies of the four engineering tool HTML files**.

## Upload

Copy the contents of this folder into the root of the portal repository:

```text
index.html
tool.html
documentation.html
document.html
about.html
tool-registry.json
assets/
schemas/
```

The portal reads each tool's live `tool-manifest.json` from its existing GitHub Pages repository.

## Live Manifest Sources

- `https://rabel-626.github.io/Downtime-Tracker/tool-manifest.json`
- `https://rabel-626.github.io/Cycle-Time-Labor-Study/tool-manifest.json`
- `https://rabel-626.github.io/Downtime-Tracker-Multi-Study-Totalizer/tool-manifest.json`
- `https://rabel-626.github.io/Material-Flow-Takt-Planner/tool-manifest.json`

The existing tool applications remain untouched in their own repositories.
